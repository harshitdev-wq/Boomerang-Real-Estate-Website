🏠 Boomerang — Real Estate Platform

A modern real-estate web platform designed to make discovering, comparing, and exploring properties feel simple, immersive, and intuitive.

Live Demo: https://boomerangrealestate.netlify.app/

Repository: https://github.com/harshitdev-wq/Boomerang-Real-Estate-Website

✨ Overview

Boomerang is a responsive real-estate platform built around a modern property-discovery experience.

The project focuses on creating a polished interface for exploring properties, viewing property information, comparing listings, browsing locations, and experiencing properties through interactive visual features.

The application is designed to work smoothly across desktop, tablet, and mobile screen sizes.

🚀 Features
🏡 Property discovery and browsing
🔎 Property search and filtering
🗺️ Interactive map-based property exploration
📸 Property photo galleries
🎥 Virtual property tour experience
⚖️ Property comparison
❤️ Property interaction and saved-state functionality
👤 User-oriented property experience
🛠️ Admin panel interface
📚 API documentation interface
📱 Responsive design across devices
🧩 Reusable React components
⚡ Fast Vite development and production builds
